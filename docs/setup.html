Setup

Two minutes for the app. Ten more if you want Google Meet links and email to guests.

DownloadBuild it yourselfGoogle MeetEmail to guestsClaudeHelp

Option A: download the app

  1. Get MeetingBlitz.zip from the latest release and unzip it.
  2. Move MeetingBlitz.app into your Applications folder.
  3. Run this once in Terminal, then open the app normally:
xattr -dr com.apple.quarantine /Applications/MeetingBlitz.app
The app is signed with a self-made certificate, not a paid Apple developer account, so macOS quarantines it. The command tells macOS you vouch for it yourself. Only run it on software you trust. Without it: double-click, click Done, then System Settings → Privacy & Security → Open Anyway.

Where is it? The app has no window and no Dock icon. Look at the top right of your menu bar.

Option B: build it yourself

No Gatekeeper warning at all, because software you compile yourself is not quarantined.

git clone https://github.com/Felixosk/meetingblitz-mac.git
cd meetingblitz-mac
./build.sh && open dist/MeetingBlitz.app

Missing Command Line Tools? Install them once with xcode-select --install, then build again.

On first launch a short welcome covers calendar access, which calendars to show and launch at login. Replay it under Settings → Advanced → Walkthrough.

Google Meet links (optional)

The Instant meeting button, Meet links on new events and email to guests talk to Google for you. That needs your own credentials. There is no shared key in the app.

  1. Open the Google Cloud Console and create a project.
  2. APIs & Services → Library: enable the Google Calendar API.
  3. OAuth consent screen: pick External, add your own Google address as a test user. (Workspace: pick Internal.)
  4. Credentials → Create credentials → OAuth client ID, type Desktop app. Download the JSON.
  5. Put the file in place:
mkdir -p ~/Library/Application\ Support/MeetingBlitz
cp ~/Downloads/client_secret_*.json ~/Library/Application\ Support/MeetingBlitz/google-oauth.json

Restart MeetingBlitz and click Settings → Meetings → Connect Google. The token lives in your Keychain, never in a file.

In Testing mode Google ends the sign-in after 7 days. The Publish button on the consent screen stops that.

Email to guests (optional)

  1. In the same Google project: enable the Gmail API.
  2. OAuth consent screen → Data access: add https://www.googleapis.com/auth/gmail.send.
  3. Switch on Settings → Meetings → Email to guests, click Reconnect Google and tick "Send email".

The app can only send, not read. Guest addresses are never stored. There is an English and a German template, and you can change the text for a single meeting in the New Meeting window.

Claude access (optional)

MeetingBlitz can act as an MCP server for Claude Code and Claude Desktop. Then you say "move my 2 pm call to 4 pm" and Claude does it.

  1. Settings → Advanced → Claude access (MCP): switch it on.
  2. Click Copy command and run it once in Terminal.
  3. Open a new Claude chat.

Claude can read calendars and events, create and move events, and delete only events it created itself. The bridge listens on 127.0.0.1 and needs a token for every request.

If something is off

The menu bar icon is missing

Space right of the notch is limited, and macOS hides icons without a message when it is full. Quit another menu bar app, or open the widget with ⌃⌥M.

The app sees no events

System Settings → Privacy & Security → Calendars → MeetingBlitz needs full access, not "add only".

Google keeps waiting

After an update macOS asks once about the Keychain item. Click Always Allow.

Status report

Right-click the menu bar icon → Save diagnostics. The report lands in Downloads. It contains your calendar names, so read it before you share it.
